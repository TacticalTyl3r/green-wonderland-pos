# Archived application snapshots

These files are intentionally retained for reference, comparison, or manual recovery. **They are not part of the active Green Wonderland website.**

- `legacy-pos/app.js` — an earlier POS entry file.
- `legacy-pos/app-receipt-v7.js` through `app-receipt-v10.js` — earlier receipt-oriented iterations.

The live deployment loads `app-pos-upgrade.js` via the root `index.html`. Do not re-enable an archived application script without reviewing its dependencies, checkout security, and compatibility with the current Supabase functions.

The original Git history also contains every archived version.
